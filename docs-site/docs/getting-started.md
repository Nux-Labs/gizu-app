# Get started

Gizu is currently in testing. To try it, request early access and install the test build on your phone.

## 1. Request early access

Go to [app.gizu.io](https://app.gizu.io) and choose **Request access**. Leave the email address where you want to receive your invitation. The Gizu team will follow up with installation instructions.

## 2. Install the app

### Android

1. Open the Android installation link from your invitation on your Android phone and download the app.
2. If prompted, allow your browser to install apps from this source, then install Gizu.

No Google Play account or testing group is required.

### iOS

iOS test builds are installed on registered devices.

1. Open the device registration link from your invitation in **Safari on the iPhone you want to use**.
2. Follow the instructions to install the registration profile.
3. Let the Gizu team know when registration is complete.
4. When your device has been added, open the installation link the team sends you.

:::note
Registering a device does not install the app on its own. Each new iPhone has to be included in a new test build, so there may be a short wait between registration and installation.
:::

## 3. Create your wallet

Open Gizu and create your wallet with a passkey. See [Passkey wallet](./passkey-wallet.md) for what happens during setup and how recovery works.
