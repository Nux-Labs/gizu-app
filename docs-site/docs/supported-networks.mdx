# Supported chains & protocols

Gizu is built to work across chains. This is the current list; more chains and protocols are added over time.

- **Robinhood Chain** is where tokenized stocks are traded.
- **Yield vaults** are available on several of these chains, depending on the protocol.

## Behind the scenes

Gizu also relies on infrastructure you don't interact with directly:

- **Aurora Confidential Intents** runs the confidential balance and converts between chains.
- **1inch Fusion** executes tokenized stock trades on Robinhood Chain.

:::note
Availability can differ between iOS and Android while Gizu is in testing. The app only offers an action when your device supports it end to end.
:::
